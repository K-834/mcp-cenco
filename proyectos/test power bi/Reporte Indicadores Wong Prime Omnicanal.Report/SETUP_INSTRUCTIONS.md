Instrucciones para activar "Mostrar elementos sin datos" en Power BI Desktop

1. Abrir el archivo .pbip o .pbix en Power BI Desktop / Fabric Desktop.
2. En cada visual que use el eje de fechas: seleccionar visual -> pestaña "Formato" -> sección "Eje X" (o "Eje") -> activar "Mostrar elementos sin datos".
3. Alternativa rápida: usar el "Format Painter" para copiar formato entre visuales.
4. Guardar el informe y publicar si aplica.

Notas:
- Los archivos de visualización están empaquetados en `definition.pbir`/.pbix y no se pueden editar de forma segura desde estos archivos de proyecto sin herramientas oficiales.
- Si deseas que automatice la modificación de visuales, exporta el informe a formato editables (si lo soporta tu versión) o indícame que genere un checklist para revisión manual.
